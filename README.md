## About

I'm **Tayyab Ali**, known online as **CodeWithDeved**: a software engineer and founder in Karachi, Pakistan. I like building at the point where engineering meets how people actually think, decide and use software.

- **Founder & CEO**, [Vibeans Solutions](https://www.vibeanssolutions.site/), a software and AI studio building web products and SaaS.
- **Software Engineer**, [Perception Tech](https://perceptiontech.org/).
- **Building** AI-powered SaaS and web products.
- **Curious about** FinTech and healthcare, GenAI, RAG, prompt engineering, human behavior and cognitive design.

> Turning complex ideas into useful, well-crafted digital products.
